# WrapStar SOP — live wrap, barcode, collection

Internal. Shopper pages never mention live video, barcodes, or contractor names.

---

## Before the window

1. Confirm the accepted wrap window in the WrapStar App.
2. If you cannot work: cancel in the App as soon as you know, and **no later than 4 hours before start**. See [sick-coverage.md](./sick-coverage.md).
3. Stage a clean wrapping surface. Charge the phone. Test camera and internet.

## Morning email (by 8am)

Each gift on today's sheet has:

1. Its own code (the same code JoyRider scans at pickup).
2. Whether it is a custom wrap, and the file to print if it is.
3. Whether it needs a cardboard box, and the anticipated size if it does.

## During the window

1. **Start shift** in the WrapStar App. That starts the clock we use for hours.
2. Open the retailer boxes and match each gift to a code from the email.
3. **Scan that code** to open the gift. Scanning does not start the camera.
4. Print the custom wrap file when the gift asks for one.
5. Tap **Start camera** and aim a table camera at the wrapping surface. Leave the phone free for the steps.
6. If the gift needs a box, pick up that cardboard box **before you cut the paper**.
7. Cut the paper, wrap the gift, and show the finished wrap to the camera.
8. Tap **Item fully gift-wrapped**. That turns the camera off.
9. Set the wrapped gift back in its original packaging when it fits. Do not tape it yet. Several gifts may share one shipper box.
10. Print that **same** code and stick it on the outside of the original packaging. One code per gift.
11. Repeat for the next gift.
12. **End shift** when the last gift is labeled. That timestamp closes the hours.

Pace is 12 gifts an hour. An order is not ready for collection until every gift on it is labeled.

## If you will not wrap

Say so in the App immediately. Stage every item at the door or wrapping entrance within **2 hours**. Do not keep goods for a pay dispute. Do not require anyone to enter your home.

## Collection

The person Wrrapd assigns collects finished wraps in the published handoff window. You do not video the handoff. You do not contact the giftee.

## After the window

Hours are the accepted wrap window, prorated to 15 minutes, with the 12-gifts/hour pace. Until the hours ledger ships, Command Center rates still apply and ops can batch by hand.
